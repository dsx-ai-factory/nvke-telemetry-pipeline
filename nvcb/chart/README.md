# NVCB Helm Library Chart

NVCB is part of the NVKE Telemetry Pipeline (NKTP). It is a Helm library chart
that expands an OpenTelemetry Collector configuration containing blueprint
declarations into native Collector configuration. It installs nothing on its
own; an application chart includes it as a dependency.
